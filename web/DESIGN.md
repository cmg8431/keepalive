# keepalive 대시보드 디자인 룰

> 사람과 에이전트가 같이 보는 단일 소스. 코드로 굳은 룰은 `src/tokens.css` 가 소유하고,
> 이 문서와 충돌하면 토큰이 우선이다. 조각(카드·행·위젯)은 `src/components/` 가 소유한다.

## 0. 한 줄 무드

**부드러운 메시 워시 위에 떠 있는 흰 위젯, 그리고 색을 쓰는 면은 히어로 하나.**

keepalive 는 "지금 내 맥이 자도 되는가"를 3초 안에 답해야 하는 물건이다.
화면은 읽는 문서가 아니라 **누르는 판**이다 — 액션이 먼저, 수치가 나중.

## 1. 컬러 — 역할이 먼저

| 토큰 | 역할 |
|---|---|
| `--bg` + body 메시 그라디언트 | 지면. 색은 여기서만 넓게 쓴다 |
| `--surface` (흰색) | 카드·행·위젯. 화면의 대부분 |
| `--fg` / `--fg-muted` / `--fg-subtle` | 잉크 3단. 중간 회색 남발 금지 |
| `--accent` (그린) | 살아있음 — 스위치 on, 활성 탭, 완료 |
| `--warn` (앰버) | 임계값 근처 (배터리·온도) |
| `--danger` (레드) | 파괴적 행동 (종료·해제) |
| 히어로 그라디언트 | 상태 하나를 감정으로 말하는 유일한 면 |

한 화면에서 컬러 면은 **히어로 하나**. 위젯을 색으로 칠하지 않는다 — 위젯은 흰색이고,
경고일 때만 숫자 하나가 앰버로 변한다.

## 2. 깊이 — 리프트를 쓴다 (retale 과 의도적으로 다름)

retale(Praize)는 그림자를 금지하고 배경 단차 + 헤어라인으로 위계를 만든다.
keepalive 는 **위젯 문법**을 택했으므로 `--lift` / `--lift-hover` 그림자를 쓴다.
대신 규칙을 건다.

- 그림자는 토큰 두 개(`--lift`, `--lift-hover`)뿐. 새 blur/offset 값을 직접 적지 않는다.
- 카드 안에 카드를 넣지 않는다. 중첩되면 프레임이 보이기 시작하고 그때부터 지저분해진다.
- 보더는 아이콘 타일·빈 상태·구분선에만. 흰 카드는 보더 없이 리프트로만 뜬다.

## 3. 밀도

| 항목 | 스펙 |
|---|---|
| 본문/행 제목 | 14px (`--text-body`) |
| 라벨 | 13px (`--text-label`) |
| 메타·섹션 라벨 | 12px (`--text-meta`) |
| 히어로 타이틀 | 17px, 값 34px |
| 위젯 값 | 24px, tabular-nums |
| 컨트롤 높이 | sm 32 · md 38 |
| 아이콘 | 15–17px, 타일은 32(기본)/36(히어로) |
| 라운드 | 컨트롤 10 · 카드 14 · 히어로 22 · 필 999 |

**12px 미만 본문, 32px 미만 탭 타깃은 없다.** 밀도는 여백으로 만들지 글자를 줄여서 만들지 않는다.

## 4. 컴포넌트 구조

```
src/
  tokens.css              토큰 단일 소스 (+ 레거시 별칭)
  app.css                 셸만: wrap · appbar · nav · panel · 활동 로그
  components/<name>/      <name>.tsx + <name>.css + index.ts
  components/index.ts      배럴
```

프리미티브: `Section` `Row`/`RowList` `Widget`/`WidgetGrid` `ActionTile`/`ActionGrid`
`Hero` `IconTile` `Lid` `SkeletonCard` `EmptyState`.

- 새 화면은 **기존 프리미티브 조합으로** 만든다. 한 화면에서만 쓰는 마크업이면 그 화면에 두고,
  두 번째 화면이 같은 모양을 필요로 하는 순간 `components/` 로 승격한다.
- 컴포넌트는 자기 CSS 를 자기 폴더에서 import 한다. `app.css` 에 조각 스타일을 쌓지 않는다.
- 각 컴포넌트 상단에 한 줄 주석으로 **왜 존재하는지**를 적는다.

## 5. 화면 문법

1. **히어로** — 상태 한 문장 + 값 하나 + 진행 도트
2. **바로 하기** — 2×2 액션 타일 (1시간/3시간 깨우기, 재우기, 새 세션)
3. **지금 상태** — 흰 위젯 2×2 (배터리·온도·뚜껑·세션)
4. **깨워두는 이유** — 행 리스트, 행마다 끄는 버튼 하나
5. **안전 장치 / 방금 있었던 일** — 조용한 리스트

설정은 **남은 항목만** 보여주는 체크리스트가 먼저다. 끝난 항목은 개수로 접는다.
QR 같은 큰 그림은 기본으로 펼치지 않는다 — "QR 보기"를 누른 사람에게만 보여준다.

## 6. 라이팅

토스 톤: 짧고, 부드럽고, 주어가 우리다.

- 상태는 사람 말로. "AWAKE" 가 아니라 "지금 깨어 있어요"
- 버튼은 동사로. "홀드" 가 아니라 "1시간 깨워두기", "그만 깨우기"
- 실패는 사과하지 말고 다음 행동을 준다. "연결 실패" 가 아니라 "잠깐 연결이 끊겼어요. 곧 다시 이어볼게요"
- 영어는 대문자 남발 금지, 문장형 유지.

## 7. 모션

- 진입: 섹션이 읽는 순서대로 34ms 씩 밀려 올라온다 (`rise`)
- 전환: 탭 인디케이터가 스프링(`--ease-pop`)으로 미끄러진다
- 상태: 히어로 메시는 19s/27s 로 서로 반대로 흐른다 — 무엇이 움직이는지 보이면 실패
- 물건은 물건처럼: 뚜껑 위젯은 힌지 각도로 열림/닫힘을 말한다
- `prefers-reduced-motion` 에서 전부 정지한다. 예외 없다.
